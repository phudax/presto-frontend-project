# Presto – Frontend (Portfolio Version)

Presto is a slide and presentation builder built as a **single-page React application**. This repository contains the **frontend** for creating, editing, and presenting slide decks with interactive elements (text, images, video, and code blocks).

> **Portfolio Notice**  
> This repository is a **portfolio-safe adaptation of a university assignment project**.  
> All original assignment specifications, marking rubrics, and course-provided materials have been removed to respect academic integrity and confidentiality.  
> This public version contains **only my implementation and original frontend code**.

---

## What This Frontend Does

The application supports:
- Authentication flows (register, login, logout)
- A dashboard to manage presentation decks
- Creating, deleting, and navigating slides
- Editing presentation metadata (title and thumbnail)
- Adding and editing slide elements:
  - Text blocks (font size, colour)
  - Images (URL or upload)
  - Videos (embed and playback options)
  - Code blocks (language-aware formatting)
- Preview mode for presenting decks
- Responsive UI and accessibility-friendly design patterns

---

## Tech Stack

## Engineering Focus

This project was built to demonstrate:
- Building a true single-page application (no page refresh for state updates)
- Clean component structure and reusable UI patterns
- API integration and robust error handling
- UI/UX thinking for editing workflows
- Accessibility-aware interface design
- Maintainable code style and consistent linting
